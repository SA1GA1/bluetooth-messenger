# Контракт MVP OffGrid

Согласованные требования от 2026-10-16. Сохранены отдельно после замены README на описание проекта.

Android 12+ (API 31). Работа без интернета и Google Play services. BLE advertising/scanning + GATT для обнаружения и коротких пакетов, системный Wi-Fi Direct для вложений. Nearby Connections исключён. Камера CameraX + встроенный ZXing.

PIN из 6 цифр обязателен. Холодный запуск и явное закрытие требуют PIN; после сворачивания — включённая биометрия, после первого отказа/ошибки/отмены — PIN. Сворачивание блокирует сразу. Таймаут 1/3/5/15 минут (по умолчанию 5) действует при бездействии в открытом приложении. При блокировке/фоне обмен останавливается, БД закрывается, рабочие секреты освобождаются. Забытый PIN: только подтверждённый локальный сброс.

Одного сканирования QR достаточно: второй пользователь подтверждает запрос, оба сверяют код знакомства и независимо вводят имена. QR содержит UUID и публичные ключи, без имени. Доверие устанавливается только после взаимного подтверждения.

Только локальное удаление; «удалить у всех»/Recall исключено. Очередь и Ack устойчивы к перезапуску; Ack после сохранения; повтор пакета не создаёт дубликат. Очистка истории отменяет её очередь и удаляет вложения.

Группой управляет создатель. Участник может выйти. Изменение состава меняет GroupKey; состав и сообщения подписаны. Каждый отправитель доставляет собственные сообщения каждому адресату напрямую. Mesh и передача управления отсутствуют.

Идентичность: полный UUID, отдельные неэкспортируемые P-256 signing/agreement keys в Keystore. StrongBox → TEE, без скрытого software fallback. ECDH + HKDF-SHA256 + AES-256-GCM + ECDSA-SHA256. Секрет SQLCipher случайный, защищён Keystore. Бэкапы/перенос приватных данных отключены.

Лимиты: текст 16 КиБ UTF-8, публичный текст 2 КиБ, фото 10 МиБ, файл 50 МиБ, группа до 8 человек включая создателя. Публичный режим без E2E и подписей, сообщения живут 24 часа, максимум 20 устройств. Точные метры не показываются. Тёмная тема фиксированная.

Вне MVP: фоновая доставка, mesh, ratchet, rotating ID, докачка, голосовые сообщения, светлая тема и остальной roadmap. Радиосвязь требует приёмки на двух физических устройствах, группы — на трёх. Сейчас доступен один телефон; автоматические проверки не заменяют аппаратную приёмку.
